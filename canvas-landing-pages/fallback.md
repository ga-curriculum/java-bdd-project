<h1>
  <span class="prefix"></span>
  <span class="headline">Java BDD Project</span>
</h1>

This project is designed to assess your ability to create a Java Spring Boot application that uses Cucumber for BDD testing. The app will use a PostgreSQL database and include at least 3 CRUD operations. Each model will have a corresponding Cucumber feature file that tests the CRUD operations. The app will be deployed online so that the rest of the world can use it.
